`NeverD.icns` renders the existing [NeverD dark logo](../../../docs/assets/neverd-logo-dark.svg)
without changing its vector geometry or colors. It contains 16, 32, 128, 256,
and 512 point icons at 1× and 2× resolution, with a transparent margin. It was
generated using `rsvg-convert` (86% of the square canvas height, centered) and
macOS `iconutil`. The icon follows the repository's existing license.

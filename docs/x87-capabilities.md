# x87 capability inventory

Generated by `scripts/generate_x87_capabilities.py` from the shared
`neverd x87-capabilities` report. Do not edit the tables by hand.

See [semantic contracts](x87-semantics.md) for ownership, qualification
and failure behavior. This inventory is not execution or proof evidence.

`implemented` means a route exists under its prerequisites. Numerical
precision and complete architectural state are independent properties.

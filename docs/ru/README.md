# Документация NeverD

Обзор проекта, сборка и CLI — в README репозитория. Ссылки по архитектуре и тестированию для участников собраны здесь.

Экспериментальная команда `neverd mobile` поддерживает восстановление исходников Android и iOS. Для Android она принимает APK (включая multidex), DEX, файлы и каталоги smali и создаёт Java и отчёт JSON. Для iOS она принимает IPA, `.app`, Mach-O (arm64 / x86_64) и создаёт нативный C, поддерживаемые исходники Objective-C / Swift и отчёт о покрытии JSON. Объём восстановления и ограничения описаны в руководствах.
